# Getting help

- **Using Pupitre** — the documentation at [pupitre.studio/docs](https://pupitre.studio/docs/) covers installing the app, enrolling a server, the service catalogue and troubleshooting.
- **A bug** — open an [issue](https://github.com/React-Consulting-SARL-AU/pupitre/issues/new/choose) with the bug report form.
- **An idea or a question about the code** — open an issue with the feature request form, or start a discussion if they are enabled.
- **Your account, a licence beyond three servers, anything private** — write to `support@pupitre.studio`.
- **A vulnerability** — never in public: see [`SECURITY.md`](./SECURITY.md).

Pupitre is maintained by a very small team. Issues are read, but answers may take a few days.
