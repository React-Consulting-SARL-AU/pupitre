## The hosted platform

The platform at `app.pupitre.studio` is free for every organisation up to {FREE_SERVERS} enrolled machines. Beyond them, an organisation needs a licence, granted by the platform on request, at no charge today, as the [free servers and licences](/legal/billing/) describe. What is counted is machines: an enrolled machine takes a seat, a removed machine frees it, and an organisation shares its seats between its members.

On the hosted platform, you do not try to enrol more machines than your organisation's seats, to forge the platform's answers, or to make the agent behave as if it held a licence it does not hold. ## Who signs the app

The macOS and Windows builds of the desktop app we publish are signed with certificates held by React Consulting SARL AU, so that the operating systems accept the app. The agent we publish is signed with an Ed25519 key that belongs to the project and that the app carries to verify every binary it installs. A build you make yourself carries neither signature, and the agent we publish installs no update that does not carry ours.

## Third-party software

The agent installs software on your machine that is not ours. Each piece keeps its own licence, which you accept by installing it. Each service in the catalogue carries the name of the software it installs; its licence is the one its publisher releases it under.

The app and the agent are themselves built on open-source components, whose licences stay theirs and prevail over this one for those components. The [third-party notices](/legal/third-party/) name them.

## Restricted mode

Without a valid right of use for seven days, or when the platform answers that the machine is suspended, the agent enters restricted mode: it refuses commands from the app and answers only that a licence is required. It stops no service, erases no data and touches no file. When the platform has answered a suspension, the agent also empties the tagged block it manages in `authorized_keys`, as the [terms](/legal/terms/) describe; when it is simply without an answer, it changes nothing. A restored right of use puts it back to work as it was.

## Termination

The right to use the hosted platform ends with the right of use of the machine, or immediately on a serious breach of these terms or of the [acceptable use policy](/legal/acceptable-use/). After termination your machine stays an ordinary machine: what runs keeps running, and the command to uninstall the agent is documented. The licence of the code ends only as the Apache License and the Commons Clause provide: selling the software is outside the rights granted, and the patent licence ends for whoever brings a patent claim over the code.
