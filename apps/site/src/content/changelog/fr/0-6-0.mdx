App et agent tous deux à mettre à jour : l’app propose la mise à jour de l’agent sur les serveurs qu’elle connaît, et chaque serveur garde le mot auquel il répondait déjà.

## L’app

- Depuis la 0.2.3, chaque clic gauche dans un terminal était transformé en Option-clic pour que le terminal garde sa sélection, et plus aucun appui n’atteignait tmux ni Claude Code — seule la molette passait. Un clic et un glisser vont désormais au programme qui a demandé la souris ; ⌥+glisser sur macOS, ⇧+glisser ailleurs, sélectionne dans le terminal. Ce qu’un programme copie — une sélection de tmux, par exemple — arrive dans le presse-papiers, et rien n’y est jamais lu dans l’autre sens.
- Chaque serveur porte un nom SSH, le mot par lequel `ssh atelier`, les éditeurs et les agents de code le joignent. Il se saisit à côté du nom à l’ajout du serveur, se modifie depuis la fiche du serveur dans Réglages › Serveurs, est tiré du nom quand rien n’est tapé, et refusé quand un autre serveur ou un hôte de votre `~/.ssh/config` y répond déjà. Un serveur ajouté avant garde le mot auquel il répondait, et changer ce nom ne ferme pas les sessions ouvertes dessus.
- Un serveur accordé par l’organisation — le second ordinateur d’une même personne — arrivait avec son empreinte épinglée et aucune clé d’hôte inscrite, si bien que les clients qui lisent le fichier SSH de l’app ne pouvaient pas le vérifier. La clé que la machine présente y est désormais écrite quand c’est celle du pin.
- Le fichier SSH de l’app nomme la clé et le `known_hosts` à travers `~/.pupitre/<dossier>`, un lien gardé pointé sur le dossier de données de l’app et remis en place à chaque démarrage. JetBrains Gateway lit ce fichier avec son propre analyseur et coupe un chemin sur l’espace d’`Application Support`, guillemets ou non, puis refuse la clé d’hôte sans rien demander ; le lien retire l’espace du chemin.
- Une entrée Aide se tient au bas de la barre latérale, et dans la palette de commande : comment ssh, Claude Code, Codex et les éditeurs joignent le serveur affiché, avec la commande, le compte et la clé lus dans le fichier SSH de l’app, si chaque outil est installé sur ce serveur, les pannes courantes et ce qui les répare, et un lien vers le guide complet.
- Un dépôt qui ne versionne ni `.env.example` ni `.env.1password.tpl` n’est plus refusé : le projet n’a simplement pas d’environnement, son panneau le dit en une ligne, et Régénérer n’est proposé que quand un gabarit existe. Un `.env.local` posé à la main sur le serveur est lu tel quel. Ceci demande l’agent 0.6.0.

## L’agent

- `project.env` dit si le dépôt versionne un gabarit. Sans gabarit, il répond sans aucune clé et n’écrit rien. Le seul refus qui reste est un gabarit 1Password sur une machine où `tool.1password` n’est pas installé, et il nomme le remède : installer l’outil, ou versionner un `.env.example` à côté pour un démarrage sans coffre.

## Limites connues

- Les versions de runtime d’un projet se choisissent dans ses réglages une fois le projet ajouté ; l’écran d’ajout ne les demande pas encore.
- Une app macOS 0.1.2 ou plus récente trouve cette version seule ; les 0.1.0 et 0.1.1 ne le peuvent toujours pas, et demandent la 0.6.0 installée depuis la page de téléchargement.
- L’installateur Windows n’est toujours pas signé : SmartScreen avertit au premier lancement.
